ProCraft: Instruction-Driven Music Production from Free-Form Text

Audio examples for the paper. ProCraft is a 0.5B codec language model that edits a 30-second mix from a freely phrased instruction: removing, extracting, accompanying, covering, re-instrumenting, denoising, and applying audio effects.

All systems run on the same test items with their released weights. Clips are loudness-normalised mono, 30 seconds.

ProCraft (ours) ★ deterministic signal processing or separation Slakh: synthetic multitracks · MoisesDB: real recordings Each example has one player: switch between the source, the systems and the target with the tabs, and playback continues from the same point. On accompaniment examples, + source mixes the output with the input.

All eight instrument families

The test sets of the paper target bass, drums, guitar and piano. These examples cover all eight families the model is trained on, from the Slakh test split: one item per task and family. Cover targets the four wide-range instruments and instrument transfer the seven pitched ones.
